# ESP32-S3 智能语音交互系统综合说明

---

## 项目概述

本项目是基于 ESP32-S3 的语音交互解决方案，集成了语音识别（STT）、自然语言处理（LLM）、语音合成（TTS）、蓝牙控制、网络音乐流播放、WiFi音频传输等功能，适用于车载语音助手、IoT 智能家居等场景。

**核心流程**：音频采集 → 百度语音识别 → 通义千问 LLM → 百度语音合成 → 扬声器播放 + 蓝牙/串口/网页控制

---

## 一、硬件连接

- **麦克风（INMP441）**：I2S_NUM_1，采集语音
- **扬声器（MAX98357）**：I2S_NUM_0，播放 TTS/音乐
- **物理按键**：GPIO3（语音识别），GPIO7（语音聊天）
- **LED**：GPIO9（状态灯），GPIO15（备用）
- **蓝牙串口**：GPIO11/12
- **STM32 串口**：GPIO13/14

详细接线见下表：

| 功能        | GPIO  | 说明 |
|------------|-------|------|
| 按钮（语音输入） | GPIO 3 | 按下时触发 STT |
| 按钮（语音聊天） | GPIO 7 | 按下时触发语音聊天 |
| LED        | GPIO 9 | 状态指示灯 |
| STM32 RX   | GPIO 13 | 接收 MCU 数据 |
| STM32 TX   | GPIO 14 | 发送至 MCU |
| 蓝牙  RX   | GPIO 11 |
| 蓝牙  TX   | GPIO 12 |

## 三、主要功能与操作方式

### 1. 物理按键操作

- **语音识别（GPIO3）**：按下后采集语音，自动识别并执行指令（如“开灯”、“关灯”、“播放音乐”等）
- **语音聊天（GPIO7）**：按下后采集语音，自动调用通义千问大模型，返回语音答案

#### 语音识别可用指令

| 语音指令         | 功能说明                 |
|------------------|-------------------------|
| 开灯             | 点亮 LED1               |
| 关灯             | 熄灭 LED1               |
| 播放音乐         | 播放当前音乐流           |
| 停止播放         | 停止音乐播放             |
| 播放下一首       | 切换到下一首音乐         |
| 播放上一首       | 切换到上一首音乐         |
| 音量增大         | 音量加                   |
| 音量减小         | 音量减                   |
| 音量调到最大     | 音量设为最大             |
| 音量调到最小     | 音量设为最小             |
| 开始导航         | 语音播报导航提示         |

如需扩展指令，可在主程序 handleVoiceRecognition() 中添加。

### 2. 串口/蓝牙指令

通过蓝牙串口（或电脑串口）发送以下文本命令：

| 指令            | 功能说明                |
|-----------------|------------------------|
| on              | 点亮 LED1              |
| off             | 熄灭 LED1              |
| play            | 播放音乐流             |
| stop            | 停止音乐播放           |
| volumeup        | 音量加                 |
| volumedown      | 音量减                 |
| next_song       | 下一首音乐             |
| previous_song   | 上一首音乐             |
| pause/resume    | 暂停/恢复音乐          |
| status1         | 语音播报“超速警告”     |
| status2         | 语音播报“请注意转弯”   |
| status3         | 语音播报“请注意倒车”   |
| status4         | 语音播报“电池电量低”   |
| status5         | 语音播报“电池已充满”   |
| status6         | 语音播报“环境噪音大”   |

#### WiFi音频相关指令

| 指令         | 功能说明                       |
|--------------|-------------------------------|
| start_tx     | ESP32麦克风→电脑音频流         |
| stop_tx      | 停止麦克风音频流               |
| start_rx     | 电脑音频→ESP32扬声器           |
| stop_rx      | 停止电脑音频播放               |
| start_both   | 双向音频流（全双工）           |
| stop_both    | 停止所有音频流                 |

#### 播放列表管理

| 指令格式                | 功能说明                       |
|-------------------------|-------------------------------|
| ADDURL:http://xxx.mp3   | 添加音乐流到播放列表           |
| PLAYLIST:[JSON数组]     | 设置播放列表（JSON格式）       |
| PLAYLIST:索引           | 按索引播放列表中的音乐         |
| LISTSHOW                | 打印当前播放列表到串口         |
| LISTCLEAR               | 清空播放列表                   |

#### TTS参数设置

| 指令格式         | 功能说明           |
|------------------|-------------------|
| SET_PER:数字     | 设置发音人         |
| SET_SPD:数字     | 设置语速           |
| SET_PIT:数字     | 设置音调           |
| SET_VOL:数字     | 设置音量           |

#### 其他指令

| 指令格式         | 功能说明           |
|------------------|-------------------|
| velocity123      | 透传到STM32串口    |
| A=数字           | 透传到STM32（可带负号） |

## 四、Web端音频操作

- 打开 2.html 网页，输入 ESP32 IP，连接后可：
  - “开始发送（TX）”：电脑麦克风→ESP32扬声器
  - “开始接收（RX）”：ESP32麦克风→电脑扬声器
  - “双向”：全双工音频
  - 支持手机和PC浏览器

---

## 五、WiFi音频功能详细说明

- ESP32 启动后自动开启 WebSocket 服务器（端口 81）
- 客户端连接后可通过命令控制音频流方向
- 音频参数：采样率 44.1kHz，16位单声道，缓冲区 2048 字节
- 支持分块传输、PSRAM 优化、任务优先级调整
- 详细命令见上表

### 故障排除

1. **无法连接到WebSocket服务器**：确认网络、IP、WiFi连接
2. **没有声音**：检查硬件连接、串口输出
3. **音频断断续续**：靠近路由器、减少任务负载、调整采样率
4. **系统重启或崩溃**：优化内存、减小缓冲区、稳定供电
5. **ESP32接收音频时重启**：检查缓冲区大小、客户端数据包大小

## 六、自动控制逻辑

- **超速检测**：测频率输入（GPIO10），每100ms采样，超速自动语音播报
- **环境噪音检测**：ADC采集音量，超过阈值自动语音播报
- **语音识别/聊天**：按键触发，自动采集、识别、播报

---

## 七、常见问题与调试

- 串口监视器可查看所有状态和调试信息
- 音频流/语音识别/蓝牙/播放列表均有详细日志
- 如遇音频卡顿、WiFi连接失败、蓝牙无响应等，可重启设备或检查硬件连接

---

## 八、开发与扩展建议

- 可在主程序 handleVoiceRecognition() 扩展语音指令
- 可在 handleBluetoothCommand() 扩展蓝牙/串口命令
- 支持自定义播放列表、TTS参数、音频流
- 支持二次开发：语音对讲机、远程监听、语音转发等
